# whispr VPN artwork

Original full-resolution generated assets:

- `logo.png`: transparent-background metallic interwoven **W**, cyan and amber edges, intended for an application icon and installer identity.
- `splash.png`: the same mark presented on a dark navy cinematic background with cyan/amber lighting, exact **whispr VPN** wordmark and a clear lower area for status text.

Created with the built-in OpenAI image-generation tool for this release. The splash used the logo as its reference image. Design brief: premium, sculptural and restrained; no borrowed existing brand symbol, padlock cliché, flags, interface screenshot or extra slogan. These are the source PNGs; `prepare.py` only crops/resizes/letterboxes them for ICO/BMP packaging, without repainting the artwork. The generated logo's transparency is preserved.

The supplied Hybrid License is included at the source-kit root.
